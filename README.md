One warm line about a small good thing that happened today, written for make.fun's "Make the Judge Smile" bounty. The program writes exactly that one line to `entry.txt`.

> This morning the train conductor held the doors for a sprinting schoolgirl, then bowed to her like royalty, and the whole carriage smiled.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/judge-smile-out python3 main.py
```

## Why the line works

It is a small, specific moment from today — not a grand gesture. The warmth is in the conductor's kindness, the surprise is the bow, like royalty, for a schoolgirl in a hurry, and the payoff lands on the whole carriage smiling, so the reader is in the carriage too. One concrete detail (the held doors, the sprint) keeps it real, and the wording is plain and fresh, with no greeting-card phrasing.
